# WordPress E2E Tests (wp-starter-kit)

Post-scaffold playbook for **consumer plugins** generated by
`@wpdev/create-wp-project` with `e2eTest: playwright`.

**Complements:** [wpdev-php-modules](../wpdev-php-modules/SKILL.md),
[wpdev-js-modules](../wpdev-js-modules/SKILL.md),
[docs/e2e-tests.md](../../docs/e2e-tests.md).

**Shared upstream skill (patterns + templates):**
[github.com/abolfazl-moeini/wordpress-e2e-tests](https://github.com/abolfazl-moeini/wordpress-e2e-tests)
(also `~/.agents/skills/wordpress-e2e-tests` when installed locally).

## Enable

```bash
wpdev create my-plugin --e2e-test=playwright
# or on an existing project:
wpdev add e2eTest=playwright
```

| Preset                                 | `e2eTest`    |
| -------------------------------------- | ------------ |
| `minimal` / `standard` / `woocommerce` | `none`       |
| `full`                                 | `playwright` |

Requires **Docker** (`@wordpress/env`).

## Emitted layout

See [references/scaffolded-layout.md](references/scaffolded-layout.md).

| Path                               | Role                                           |
| ---------------------------------- | ---------------------------------------------- |
| `.wp-env.json`                     | Maps `"."` as the plugin; permalink lifecycle  |
| `playwright.config.js`             | Extends `@wordpress/scripts` Playwright config |
| `tests/e2e/config/global-setup.js` | REST auth + storageState + content reset       |
| `tests/e2e/specs/*.spec.js`        | Admin + front-end smoke specs                  |
| `package.json` scripts             | `wp-env`, `test:e2e`                           |

Canonical templates live in
`packages/create-wp-project/src/generators/templates/e2e/`.

## DO / DON'T

**DO**

- Import `{ test, expect }` from `@wordpress/e2e-test-utils-playwright` only.
- Use fixtures: `admin`, `editor`, `requestUtils`, `pageUtils`.
- Prefer `page.getByRole()` / accessible locators.
- Seed data with `requestUtils` (REST), not slow UI clicks.
- Run interactively when debugging: `--ui` or `--headed`.

**DON'T**

- Don't import `test` from `@playwright/test` in specs.
- Don't invent Cypress / Puppeteer / fake `wp:serve`.
- Don't run against production — global setup deletes posts and resets preferences.
- Don't commit secrets for remote `WP_BASE_URL` sites.
- Don't ship `.wp-env.json` / `playwright.config.js` / `tests/e2e` in release zips (stripped automatically).

## Writing tests

Minimal admin:

```javascript
import { test, expect } from "@wordpress/e2e-test-utils-playwright";

test("dashboard loads", async ({ admin, page }) => {
  await admin.visitAdminPage("/");
  await expect(page.getByRole("heading", { name: "Dashboard" })).toBeVisible();
});
```

Minimal front-end:

```javascript
test("published post is visible", async ({ requestUtils, page }) => {
  const title = "E2E smoke post";
  await requestUtils.createPost({ title, status: "publish" });
  await page.goto("/");
  await expect(
    page.getByRole("heading", { name: title, level: 1 }),
  ).toBeVisible();
});
```

More patterns: [references/writing-tests.md](references/writing-tests.md).

## Commands

```bash
npx playwright install --with-deps   # once
npx wp-env start                     # or let webServer start it
npm run test:e2e
npm run test:e2e -- --ui
npm run test:e2e -- --headed
```

Existing Docker site (no wp-env webServer): [references/existing-environment.md](references/existing-environment.md).

## Disable

```bash
wpdev set e2eTest=none
# or
wpdev remove e2eTest
```

Owned paths are removed; `refreshGlue` updates `package.json` scripts/devDeps and `.github/workflows/ci.yml`.
