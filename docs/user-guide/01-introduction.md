# ۱. معرفی و راهنمای شروع کار

این مستند راهنمای کاربری و تنظیمات سامانه افزونه **{{name}}** می‌باشد. این افزونه بر پایه فریم‌ورک استاندارد WPDev و ساختار ماژولار توسعه یافته است.

::: note
این راهنما مستقیماً درون مخزن افزونه (In-Repo Docs-as-Code) نگهداری می‌شود و همگام با نسخه‌های جدید کد به‌روزرسانی می‌گردد.
:::

## پیش‌نیازهای سامانه

- وردپرس نسخه {{wpMinVersion}} یا بالاتر
- PHP نسخه {{phpMinVersion}} یا بالاتر
- پایگاه داده MySQL 5.7+ یا MariaDB 10.3+

## مراحل نصب و راه‌اندازی

۱. فایل فشرده افزونه را از بخش **افزونه‌ها > افزودن** در پیشخوان وردپرس بارگذاری کنید.
۲. بر روی دکمه **فعال‌سازی** کلیک نمایید.
۳. پس از فعال‌سازی، منوی اختصاصی افزونه در پیشخوان وردپرس در دسترس خواهد بود.

::: tip
در صورت نیاز به بررسی وضعیت عملکرد یا گزارش باگ، به بخش مستندات فنی در `docs/technical/` مراجعه فرمایید.
:::
